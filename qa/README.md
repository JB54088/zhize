# 知择 V0.3 QA

API 契约一致性测试位于 `test_search_contracts.py`，覆盖任务创建/分页查询、阶段快照、Agent action 记录、模型用量、结论引用以及通用决策结果字段。LLM Infrastructure、AI Agent 与后端测试分别位于服务目录；前端检查由 web workspace 脚本维护。

## 本地运行

```bash
python -m pip install -r qa/requirements.txt
python -m pytest qa
```

## 验收清单

- 后端创建搜索任务并返回 `task_id`；四个阶段按小采→小洗→小验→小判执行，轮询能读到真实阶段状态、耗时和完成计数。
- 部分成功、失败和超时均保留已完成阶段快照及可用结果；分页读取不能丢失任务状态。
- 搜索结果由 AI 引擎传回，通用判断、条件和证据来源结构与两个 OpenAPI 契约一致。
- AI 引擎未配置搜索源时返回明确错误，不返回示例或合成搜索结果。
- 每条结果的 URL 和摘要来自配置的真实搜索源；证据能在来源内容中定位，判断理由引用对应来源。
- 招聘场景核验公司、岗位、专业、届别、截止和投递来源；政府采购场景验证相同引擎仍能输出逐字段官方证据状态。
- LLM 未配置时不发请求并记录 `skipped_unconfigured`；超时、错误响应、结构不合约或引用校验失败均为明确失败状态，不能伪装成模型成功。
- 每个结果结论均指向已核验结果 ID 和逐字证据；模型语义分数不覆盖硬条件规则决定。
- 前端折叠原始正文，显示可核验摘要、关键条件、阶段真实状态和移动端/桌面布局。
- 自动化测试使用 mock/本地测试数据库，不访问生产服务；有凭据的实时搜索验证需显式配置本地开发密钥后人工执行。
